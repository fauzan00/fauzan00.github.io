Task- Get the Frequent number

Given a random non-empty array of integers, write a script that is able to output the integer number that appears the most.

Kindly do not use any library functions to directly return the most common number, as doing so will result in immediate failure.

Example:
Input:nums =[3,2,2,2,2,2,3,4,5] Output:2

Input:nums =[1,2,3,4,5,5] Output:5

Answer and Explanation

Algorithm Approach (No Library Functions):
This solution uses only basic loops and comparisons - no indexOf(), map(), filter(), or other array methods.

Step 1: Loop 1 - Insert into Array and Count
Loop through the input array:
• If number is new → Add to numbers[] array and set counts[] = 1
• If number exists → Increment its count in counts[] array

Step 2: Loop 2 - Find Maximum Count
Initialize: max = 0, id = 0
Loop through counts[] array:
• If counts[i] > max → Update max = counts[i] and id = i

Result: numbers[id] is the most frequent number

JavaScript Implementation: 
function findMostFrequent(nums) {
  let numbers = [];
  let counts = [];
  let size = 0; // Track array size manually
  
  // Loop 1: Count occurrences
  for (let i = 0; nums[i] !== undefined; i++) {
    let found = false;
    let index = -1;
    
    // Check if number exists
    for (let j = 0; j < size; j++) {
      if (numbers[j] === nums[i]) {
        found = true;
        index = j;
        break;
      }
    }
    
    if (!found) {
      numbers[size] = nums[i];
      counts[size] = 1;
      size++;
    } else {
      counts[index]++;
    }
  }
  
  // Loop 2: Find maximum
  let max = 0;
  let id = 0;
  for (let i = 0; i < size; i++) {
    if (counts[i] > max) {
      max = counts[i];
      id = i;
    }
  }
  
  return numbers[id];
}
